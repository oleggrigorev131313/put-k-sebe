# Путь к себе — backend

Backend для Telegram Mini App на Yandex Cloud: API Gateway → Cloud Functions (Python 3.12) → YDB Serverless.

## Что входит

- Серверная проверка подписи Telegram Mini App initData. Клиентские данные initDataUnsafe не используются для авторизации.
- Облачное сохранение состояния пользователя (дневник, паттерны, выполненные практики, onboarding).
- Обязательная изоляция данных по Telegram user ID.
- Lockbox для токена бота; токен не попадает в GitHub и браузер.
- Отдельная таблица обезличенных событий использования без содержимого дневников.
- API: GET /health, GET/PUT/DELETE /v1/state.

## Что пока не подключено

- ИИ-анализ, автопредложение паттернов и AI Studio.
- Платежи, подписки и Tribute.
- Панель администратора (аналитические события уже записываются; доступ к сводке добавим с отдельной проверкой Telegram ID администратора).
- Завершённый юридический контур для обработки персональных данных. До публичного запуска нужны тексты согласия, политика конфиденциальности, сроки хранения и порядок удаления, проверенные с юристом по применимому законодательству.

## Развёртывание

Из корня Cloud Shell:

    git clone https://github.com/oleggrigorev131313/put-k-sebe.git
    cd put-k-sebe
    bash backend/deploy.sh

Скрипт использует уже созданные облако, папку, базу и сервисный аккаунт. Он создаёт Lockbox secret при первом запуске, Cloud Function и API Gateway. Токен бота вводится через скрытый prompt в терминале.

После развёртывания скрипт напечатает API Gateway URL. Этот URL нужно добавить в frontend-конфигурацию и опубликовать новый commit в GitHub Pages.

## Переменные функции

- YDB_ENDPOINT — endpoint без database path.
- YDB_DATABASE — полный путь базы из endpoint.
- BOT_TOKEN — значение из Lockbox, передаваемое Cloud Functions как secret.

## Модель хранения

user_state содержит один JSON-документ на Telegram user ID. Дневниковые записи не доступны администратору через API.
analytics_events содержит только тип события, внутренний Telegram ID, время и пустые/служебные метаданные; тексты дневников туда не записываются.

Сервис предназначен для саморефлексии и не является медицинской диагностикой или лечением.
